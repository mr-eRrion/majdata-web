## 负载范围调整

用户补充：实际单张谱面通常为 1,000 音符量级，50,000 音符测试过严。常规验收据此改为 300 秒 / 1,000 音符；10,000 音符保留为压力观察，取消 50,000 音符测试。常规帧间隔、反馈和导入等时延预算保持不变。此调整来自使用场景说明，不将已有压力测试失败抹去。

调整前的 Apple M4 / macOS arm64、Chromium 153 headless、1920×1080 DPR 1 首轮 10,000 音符测量：热导入 10 次（另预热 2 次）P95 150.2 ms；5 秒播放帧间隔 P95 33.4 ms，超过 33.3 ms 的比例 21.3%；无媒体定位 P95 53.4 ms。该版本绘制未达到原 10k 帧目标，后续对照 1k 常规负载定位实际瓶颈。导入测量从主线程发送到收到真实 WASM + 内核快照，不包括文件读取和 React 绘制；主页面 JS 堆约 22.3 MB 不能解释为总内存。
