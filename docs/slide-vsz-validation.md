# v/s/z 路径闭环验收

## 实现与边界

在原有 `-<>w` 上增量开放小写 `v/s/z`。`v` 的端点距离仅允许1、2、3、5、6、7，`s/z` 仅允许4；大写 `V`、`p/q/pp/qq` 等其余路径和现代逐段括号仍只读。8条新增轨迹、真实分片和长度直接来自原序列化数据，合计29条普通路径；来源、镜像差异见 [源核对](slide-vsz-source.md)。原21条路径和Wi-Fi规则保留。

现有解析DTO schema 4和检查点schema 5继续使用，新增命令不引入字段；旧程序遇到未知命令会在恢复校验时拒绝。单段、共享头及旧式单括号连续路线共用这些命令；每支独立等待/移动，连续段按源长度分配总移动时间，Wi-Fi仍只能独立成支。镜像时s/z在两轴均交换，v不变；旋转仅映射端点。原s/z点列不是完全镜像，测试按源规则验证命令，并记录约0.03746场景单位的镜像残差，不重造路径。

候选按钮和手绘均可提交新路径，未开放的手绘命中继续提示且不降级替换。属性切到s/z时自动采用对向端点；切到v且旧端点为同轨或对向时，选择下一轨作为有效端点。这是现有Web属性菜单的端点适配；原生面板操作仍待运行对照。共享头逐支修改、连续草稿、单次保存及取消沿用同一事务路径。
