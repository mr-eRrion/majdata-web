# 单段 Slide 模型与验收

本轮 V3.1 在现有 StrictSimaiParser 与 Chart Core 中扩展单段 `-`、`<`、`>`、`w`，不新增 Simai 解析器。此页记录数据语义与本地证据，不表示目标播放器兼容或 Slide 编辑已经开放。

## 数据与边界

每个 Slide 保留起点、终点、原路径命令、头部种类、头部 Break/EX、独立路径 Break，以及 `wait` / `move` 两个非短音符时长表达。时长可以是起点 BPM 拍数、指定 BPM 拍数或固定秒数；不能只存总秒数，因为改变 BPM 后三种表达的含义不同。`moveStartSeconds = startSeconds + waitSeconds`，`endSeconds = moveStartSeconds + moveSeconds`。后续 BPM 事件不会改写已经选定的时长基准。

解析协议升级为 schema 2，文档检查点升级为 schema 3。旧检查点保留可下载原稿并提示不兼容，不自动迁移。普通谱面仍由同一 Worker 完成导入、编辑、候选重解析与恢复。

基础 Slide 通过结构解析后仍保持整难度只读，并提示 `slide-validation-pending`。单段 `-`、`<`、`>` 与 `w` 已接入原 PNG 皮肤的 Pixi 预览，配有合成提示音，但不参与可编辑工具。连接段、共享头及尚未完整建模的修饰符继续保留原文，不显示为完整路径。无头 Slide 不计入有头音符的同拍 each；这不代表路径 each 的所有组合已验证。

## 独立时间预期

下表均以 hit=0、谱面起点 BPM=120 为基准。拍长公式为 `beats × 4 / division × 60 / bpm`，不是 `beats × 60 / bpm`。

| 表达 | 等待秒数 | 移动秒数 | 移动起点 / 结束 |
| --- | --- | --- | --- |
| `1-5[4:2]` | 0.5 | 1 | 0.5 / 1.5 |
| `1-5[240#8:1]` | 0.25 | 0.125 | 0.25 / 0.375 |
| `1-5[240#0.5]` | 0.25 | 0.5 | 0.25 / 0.75 |
| `1-5[0.25##0.5]` | 0.25 | 0.5 | 0.25 / 0.75 |
| `1-5[0.25##8:1]` | 0.25 | 0.25 | 0.25 / 0.5 |
| `1-5[0.25##240#8:1]` | 0.25 | 0.125 | 0.25 / 0.375 |

若在 hit 之后加入 BPM 变化，上述时长仍按各自表达的固定基准计算。应分别核验 MajSimai 原始输出、严格 DTO、Web 派生时刻与原文保存；实现与测试互相一致不足以证明人工预期正确。

## 验收状态

2026-09-27，真实 Release WASM 已重新发布，在现有 Chromium 153.0.8010.12 中通过 `tests/slide-browser.mjs`：10 个单段代表音符的路径、头部、修饰符、等待及移动时刻符合人工预期；连接、共享头、`?` 写法均产生诊断且不输出被截断的基础 Slide。修改普通难度后，只读难度字段保持原字节；候选导出、重新打开和 schema 3 检查点恢复均通过，无页面异常。[结果](results/2026-09-27/slide-model.json)。模型检查随后已在本地生产预览重复通过，使用实际发布的 WASM。

C# 适配层逐音符与整谱核对固定上游的类型、头部与路径修饰符、开始、移动开始和移动时长。上游输出没有可独立比较的路径命令与终点 DTO 字段，这两项来自严格源词法解析，不能称为上游独立确认。

`tests/slide-roundtrip-browser.mjs` 另在浏览器直接调用实际 `serializeChart` 与发布的 WASM 桥接，6 种时长形式、24 种头部/Break/EX/路径 Break 组合全部通过；核对生成文本、时长 DTO、秒数和上游一致性诊断，同时确认解析图仍只读。[30 例逐项结果](results/2026-09-27/slide-roundtrip.json)。这项测试没有替换解析器，也没有开放界面编辑。

`tests/slide-preview-browser.mjs` 另对实际 Pixi 层和原 PNG 资源做了三种代表路径的浏览器检查：直线 `1-5`、弧线 `2<6`、Wi-Fi `1w5`。17 张截图覆盖空白基线、各阶段和缓存重建；可见状态非空、等待与移动帧不同、结束为空、seek 与重建均逐字节复现，Wi-Fi 中点计数为 6 个箭头和 3 个星形，页面错误为 0。该检查验证 Web 预览层的状态和重复绘制，不是目标运行时的像素对照。

单段变换内核已按 `OperationUtility.FlipNotes/RotateNotes/RotateSlideFragment` 接入：水平镜像交换 `<`/`>`，垂直镜像保留；45°旋转仅在起点跨过 `{1,2,7,8}` 与 `{3,4,5,6}` 分界时交换。起点和终点一起变换，头部、修饰符及 wait/move 表达保持不变。测试用 21 条序列化基础路径、8 个起点和四种变换逐点核对几何；生产内核不依赖 Web 路径资源。这里只验证纯变换函数，没有解除 ChartEngine 或界面的只读保护。

本次预览、排序与变换集成后，全库 55 项单元测试通过。目标 Visual Maimai / MajdataPlay 的原生等待、移动、结束和 seek 中段参考帧仍未取得；Slide 编辑尚未开放，提示音沿用合成音色，原包音色未接入。
