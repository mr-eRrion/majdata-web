# 目标程序运行对照采集

静态反编译和场景提取已经能够提供参数；此清单用于补齐仍缺少的运行证据。当前 macOS 环境没有已确认可运行 Visual Maimai / 固定 MajdataPlay 的 Windows 环境。没有为此安装 Unity、虚拟机或额外浏览器。

使用 [自制对照谱面](../fixtures/charts/visual-reference.maidata.txt)，不需要用户歌曲；需要声音时使用已有 `fixtures/audio/reference-tone.wav`，记录音频长度是否覆盖片段。目标 Visual Maimai EXE / 主程序集哈希以 [逆向记录](visual-maimai-reverse.md) 为准。MajdataPlay 另记录构建来源、可执行文件哈希和实际对应提交，不能只写仓库源码提交。

## 固定条件

记录显示版本、实际窗口客户区尺寸、系统缩放、经典皮肤、speed / touchSpeed、beatScale、轨道顺序、设备校准。默认建议客户区 1920×1080、100% 缩放、speed / touchSpeed=8、beatScale=2、设备校准=0；这些是采集建议，不能写成已测环境。保留带设置值的一张图。

## 最少采集内容

1. 工作区全图：工具、时间轴、波形、预览、歌曲与播放区域都可见。切换 Tap、Hold、Touch 并显示一次选中音符属性。
2. Tap/Hold：难度 1 在谱面秒 1.9、2、2.25、4、4.25、4.75 附近暂停截图；至少记录 each、break+EX、Hold 远端截断和尾端出现。录制一次 Hold 两次点击放置、右键取消、拖动、撤销与导出重开。
3. Touch：难度 2 的四片接近、中心点、TouchHold 起点/中段/终点；记录进度环起始方向与消退方向。对象坐标和边框来自静态数据，运行图用于交叉校验。
4. Slide：难度 3 的每个基础轨迹记录 hit 前 0.1 s、等待中段、移动中段、结束，以及从结束后直接 seek 回中段。难度 4 对 Wi-Fi 做同样检查，确认三颗星和 11 个空间部件。
5. 语义差异：难度 5 跨 BPM Hold 在两个程序中分别记录结束时间和重导出的表达。难度 6 是两段不等时连接写法，允许目标拒绝；记录实际结果，不能转换成另一种写法后宣布通过。难度 7 是共享头，另记录条带 each 与头部状态。

每条证据记录原文件、难度、谱面时间和程序设置。视觉相符、操作相符、导出语义相符是三种不同结论；拒绝导入、显示差异和导出变更也是有效结果，应原样保留。截图 / 录像可放本地 `.tools/target-capture/`，报告只保留必要代表帧和清单，不自动分发用户环境资料。
