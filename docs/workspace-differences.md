# V0/V2 工作区与桌面目标差异

日期：2026-09-27。本清单依据目标包的序列化场景与 R3/R4 静态恢复，并对照当前 Web 源码及 warning 验收提供的 1920×1080、DPR 1 工作区截图。它说明来源和实现落点，不代表原生运行或像素一致验收。

| 项目 | 目标静态证据 | Web 落点与差异 | 状态 |
| --- | --- | --- | --- |
| 工作区比例 | `Editor Canvas` 的 `Scale` 为 1920×1010；CanvasScaler 参考分辨率 1920×1080，MatchWidthOrHeight 的 match 值为 1（偏高度匹配）。左侧 `Track Panel` 宽 570。右侧 `Right Panels` 宽约 1350，子项为 `Property Panel` 与最小宽 680 的 `Info Panel`，静态可分为约 670+680。见 [`desktop-layout.json`](../fixtures/visual-maimai/desktop-layout.json)（对象 53、253、552、74、379）与 [`visual-scene.md`](visual-scene.md)。 | [`styles.css`](../apps/web/src/app/styles.css) 将宽屏工作区分为时间轴、工具属性、圆形预览三栏；在 1920px 视口下使用约 29.69% 的时间轴列和约 35.42% 的预览列，中间列弹性填充。8px 列间距、10px 内边距、面板边框和 1250px 响应式断点使实际尺寸不等同于 Unity RectTransform。[`App.tsx`](../apps/web/src/app/App.tsx) 中三栏内容分别是 Timeline、工具/属性与预览；现有截图也显示这一结构。 | 比例按目标参考，Web 布局已实现；面板归属和响应方式是 Web 适配，未做原生同屏测量。 |
| 预览与歌曲信息 | `Info Panel` 先放 `View Panel`，底部 `Song Info Panel` 高 230；`View Base` 左右各留 80、上下减少 145。目标参数见 [`desktop-layout.json`](../fixtures/visual-maimai/desktop-layout.json)（对象 160、258、518）及 [`visual-scene.md`](visual-scene.md)。 | [`App.tsx`](../apps/web/src/app/App.tsx) 在预览栏内将圆形预览放在上方，歌曲名、时长和采样信息放在其下；[`styles.css`](../apps/web/src/app/styles.css) 让预览区域弹性伸展。Web 不沿用固定 230px 高度，也在该栏继续显示诊断。 | 结构关系接近，尺寸自适应；原生有效分辨率及运行时裁切待验。 |
| 时间方向与速度 | R3 的 `NoteTrack` / `TouchTrack` 公式为 $y = 200 + (t_{note} - t_{playhead}) \times 150 \times beatScale$。Unity 局部 y 向上，因此未来在上方；R4 静态构造默认 `beatScale=2`，对应 300 单位/秒。设置可由用户保存值覆盖。见 [`visual-reverse-r3.md`](visual-reverse-r3.md) 与 [`visual-reverse-r4.md`](visual-reverse-r4.md)。 | [`Timeline.tsx`](../apps/web/src/timeline/Timeline.tsx) 用默认 300px/s，播放头约距画布底部 200px；top-down Canvas 通过 `yAtSeconds()` 将未来时间映射到更小的 y（同文件的 `getGeometry()` 和 `yAtSeconds()`）。拍点位置仍经 BPM 分段换算，再按当前吸附细分落点。 | 方向、源默认比例及播放头锚点有静态对应。目标实际保存的 `beatScale`、缩放和屏幕裁剪尚无运行对照；Web 的连续时间光标和吸附策略属于显式适配。 |
| 编号轨道与 Touch 轨 | 目标普通轨道顺序为左至右 8→1，单轨宽 47、中心距 45；Touch 是独立末列，左偏移 360、宽 47。`Slide Track` 覆盖编号轨，不另占一列。见 [`desktop-layout.json`](../fixtures/visual-maimai/desktop-layout.json)（`Track (1–8)`、对象 59、45）及 [`visual-reverse-r3.md`](visual-reverse-r3.md)。 | [`Timeline.tsx`](../apps/web/src/timeline/Timeline.tsx) 的 `LANE_ORDER` 为 8→1，并在 `getGeometry()` 中用 45:47 比例分配编号轨与右侧 Touch 列。左侧 40px 标签栏加 40px 告警栏占 80px；Touch 音符落在独立列。[`TouchSensorPicker.tsx`](../apps/web/src/app/TouchSensorPicker.tsx) 使用共享源位置数据提供 33 个区域/传感器点；触点和待放置时间分别由 Timeline 与工具栏状态维护，见 [`App.tsx`](../apps/web/src/app/App.tsx)。 | 顺序、宽度比例、独立 Touch 列和源触点数据已接入。Web 列宽随可用空间缩放，标签/告警栏也合并承担目标左侧标记区域职责；实际 Canvas 像素尺寸未声称相等。 |
| 空白处右键菜单 | R3 静态源码显示：有效轨道空白处右键抬起打开 Edit 下拉；命中音符时删除；待放置手势优先处理。菜单含 20 项，覆盖撤销/重做、选择与音符剪贴、变换、Break/EX、告警导航。来源和限制见 [`edit-menu-source.md`](edit-menu-source.md) 与 [`visual-reverse-r3.md`](visual-reverse-r3.md)。 | [`Timeline.tsx`](../apps/web/src/timeline/Timeline.tsx) 先处理粘贴、Slide/Hold/TouchHold 草稿和命中删除，再在空白有效网格右键抬起发出菜单请求。[`App.tsx`](../apps/web/src/app/App.tsx) 保留源菜单顺序；项目验收记录确认菜单聚焦、外部关闭等 Web 行为，见 [`edit-menu-validation.md`](edit-menu-validation.md)。 | 主要打开条件和动作顺序依静态源实现。Web 根据选中/剪贴状态禁用菜单项，并增加 Escape 与键盘焦点支持；目标静态类未发现 Escape 关闭。BPM keyframe 剪贴由本轮新增实现，详见 [`event-clipboard-validation.md`](event-clipboard-validation.md)；拍号 keyframe 剪贴独立待做。告警检查也由 Web 独立实现，不能据菜单相同推定告警算法相同。 |
| 快捷键与鼠标手势 | R3 查到 Space 播放/暂停，逗号和 Backspace 按网格前进/后退，Ctrl+O/P 调速，按住 Tab 临时试听；在轨道悬停时左右方向键每 0.2 秒快速放置。Ctrl+左键可复制 Slide 命令文本。滚轮 + Shift 移动一小节，中键按事件位移拖动时间并在松开时吸附。见 [`visual-reverse-r3.md`](visual-reverse-r3.md) 与 [`timeline-scrub-validation.md`](timeline-scrub-validation.md)。 | [`App.tsx`](../apps/web/src/app/App.tsx) 实现 Space、`,` / Backspace、Ctrl/Cmd+O/P、Tab 试听、剪贴与撤销；Tab 在表单和菜单内让给浏览器。[`Timeline.tsx`](../apps/web/src/timeline/Timeline.tsx) 实现左右快速放置并使用逻辑光标，也处理滚轮与中键拖动。当前未发现 Ctrl+左键复制 Slide 命令文本的对应 Web 操作。 | Web 的中键拖动按源采用增量更新谱面/歌曲时间，松开后吸附；真实目标运行手感仍待比较。Web 对逗号/Backspace 的时间步进要求已载入谱面且处于暂停状态，R3 静态摘要不足以据此断言源行为不同。Ctrl/Cmd+滚轮缩放属于 Web 扩展；DOM 滚轮方向与 Unity 输入轴符号相反。 |
| 波形与歌曲播放控件 | Fixture 只确认 `Wave Track` 在 `Tracks Base` 中，以及底部 `Song Info Panel` 的层级和尺寸；R3/R4 确认谱面时间扣除 `Chart offset`、歌曲位置加回该 offset，设备音频偏移另行处理。它没有提供足够数据恢复全部原生播放控件的位置。见 [`desktop-layout.json`](../fixtures/visual-maimai/desktop-layout.json)（对象 334、258）、[`visual-scene.md`](visual-scene.md) 与 [`visual-reverse-r4.md`](visual-reverse-r4.md)。 | [`Timeline.tsx`](../apps/web/src/timeline/Timeline.tsx) 将波形绘制在时间轴左侧刻度区；[`App.tsx`](../apps/web/src/app/App.tsx) 将播放、时间、seek、变速、循环和设备校准放在全局底栏，曲名和格式信息留在预览栏下方。`&first` 在工具/属性栏编辑；[`transport.ts`](../apps/web/src/audio/transport.ts) 以 Web Audio 时钟协调谱面和歌曲时间。 | R4 时间域拆分在 Web 设计中保留；控件排布是 Web 工作台适配。目标原生的播放条完整位置、波形绘制尺寸及实际设备偏移行为需目标运行数据确认。 |

本清单只对比已提取的场景数据、静态反编译结论和当前 Web 源码。R3/R4 没有运行 Windows 目标程序；默认设置不等于用户当前设置；浏览器截图只说明 Web 当前结构。任何像素级、运行时响应或播放手感结论都需要固定目标设置后再做原生运行对照。
