# 圆形 NotePlaceArea 输入验收

## 来源与实现范围

源程序组件和41个按序列化顺序排列的区域来自 [场景证据](visual-note-place-area.md)。`extract_rendering.py` 从 NotePlaceArea 的 PPtr 定位位置资产，完整消费组件68字节、位置资产716字节；`prepare-rendering.mjs` 投影到 `parameters.notePlaceArea`。分区使用全部41个中心的最近点，等距取后者，活动半径5.5；Ring命中中心半径4.8，与绘制轨道约4.792分开保存。网页使用当前预览的世界坐标变换，命中和绘制随容器缩放保持重合。

外圈 Tap/Hold 和 Touch/TouchHold 分别保存工具状态。圆形左键按住跨区调用各自放置流程，同一次手势在同一区域停留不重复调用；离开后返回则重新检查是否已有音符。Hold 保留首点轨道，以第二次 Ring 放置时间确定另一端；允许零时长。TouchHold 跨圆形分区不能结束，终点来自 Touch 时间轨。切换同族或跨族工具保留待定端点。每次成功新增或删除为一个撤销记录；起点暂存、重复落点和无命中删除不创建历史。

圆形右键按住跨区逐个删除：Ring 优先同拍 Tap，其次覆盖当前时间的 Hold；Touch 优先同拍 Touch，其次覆盖当前时间的 TouchHold，区间含两端。含 Slide 的难度仍只读。圆形右键删除与时间轨右键取消待定长音符分别处理。

界面接收快速跨区输入；圆区、传感器面板和时间轨的放置、删除、拖动先按输入顺序处理，再由既有 Worker 队列确认。每步通过只读 `getSnapshot` 读取已确认快照，避免依赖 React 重新渲染的时机；后台忙碌不会禁用圆区。等待提交时暂不启动播放，导入/恢复期间单独隔离输入。输入区域越界、负时间、播放、只读难度均不修改；结束/取消指针、失焦、文档或难度切换、模式切换会结束手势。

## 明确保留的差异

- 源程序在左/右按下的那一帧只清空 `_lastArea`，下一帧 held 时才执行首笔。网页在有效 pointerdown 立即执行首笔，后续按实际 pointermove 跨区；不模拟源程序的帧轮询延迟。
- Hold/TouchHold 反向端点排序后，网页还会检查最终起点是否已有同类/同sensor音符，避免新增重复；源程序只检查首次端点。
- 网页保留明确的“选择”模式，左键点击可见音符用于选择。选择其他工具后才开启圆形左键绘制；两族工具分别记忆。右键在选择模式也可删除。
- 悬停圈和十字是网页输入辅助，并非原 Place Pointer Sprite 的像素复现。网页圆形容器和背景布局尚未通过目标窗口运行对照。
- 完整中键工具模板（部分已接入，见 [中键验收](tool-template-validation.md)）、SlidePlacePanel 路径绘制、目标窗口的运行对照仍未完成；左右方向键已在后续阶段接入，见 [方向键验收](fast-placement-validation.md)。本项不构成 V2 全阶段通过，也不开放 Slide 编辑。

## 验证入口

- `apps/web/src/preview/place-area.test.ts`：41中心、外边界、等距顺序、宽高不等容器的坐标变换。
- `tests/place-area-browser.mjs`：真实页面和 WASM 编辑内核，涵盖快速跨族输入、重复、逐笔撤销、右键删除、独立长音符状态、导出重开及输入禁用条件。

2026-09-27：58项单元测试、类型检查、素材生成一致性检查和生产构建通过。已有 Chromium 153.0.8010.12、1920×1080、DPR1 下，圆形输入测试通过，页面异常为0；详细记录见 [浏览器结果](results/2026-09-27/place-area.json)。

一次连续手势快速访问41个中心后再重复一遍，只产生41个音符和41条历史。额外人为延迟Worker编辑150/500ms，验证 add→remove→add 的3次历史与逐次撤销、排队中的圆形起点接Touch时间轨终点，以及圆形新增后时间轨右键删除。另覆盖工具切换保留两族pending、零时长固定首lane、Hold中段删除、越界/负时间/播放/只读限制、其他指针取消不打断主手势、失焦取消、文档替换隔离与导出重开。

基础编辑（复制/撤销/导出重开/IndexedDB恢复）、原P3（Touch/多难度/属性/导出）、纵向时间轨（反向端点、跨BPM、取消/拖动/撤销）和故障流程（存储不可用、候选导出拒绝、Worker退出后显式恢复、坏音频）均通过回归。代表截图见 [41区输入](results/2026-09-27/place-area-41.png) 与 [双族长音符](results/2026-09-27/place-area-holds.png)，已人工查看布局。

本轮浏览器检查额外暴露并修复了谱面切换时的皮肤就绪竞态：绘制现在核对就绪资源对应的snapshot和difficulty，防止以旧谱面的就绪标记读取新Slide纹理。该修复属于本轮输入/导入流程所必需的关联修改。
