# 单括号连续 Slide 本地验收

日期：2026-09-27。范围是基本 `-<>` 路径组成的旧式单括号连续路线，例如 `1-3-7[4:4]`；一条路线最多 64 段，同一头最多 64 条分支。Wi-Fi 可以是独立共享头分支，不能与普通段串联。

## 模型与来源

首段仍使用 `SlidePathData.command/endPosition`，`continuations` 只保存后续段的命令和终点；下一段从上一段终点开始。整条路线只保存一组等待和总移动时长，路径 Break 作用于整条路线。`additionalPaths` 是共同头部下的独立分支，每支可以有自己的连续路线和时长。这两个层级在编辑、复制、变换和导出中分别处理。

段边界按 Visual Maimai 的源 Path.Length 比例编译，轻量长度表与 Web 路径坐标由同一份提取数据生成，并在资源检查中同步核验。每条路线只有一颗移动星，走完的段隐藏，当前段逐渐消退，后续段保留完整条带；续段使用自己的起点旋转。时间轴用逐段时间和端点画辅助折线。播放提示音仍仅为头部、路线移动开始和 Break 尾部，不在内部连接点重复触发。

来源见 [连续路线源码](slide-connected-source.md) 和 [编辑交互源码](slide-connected-edit-source.md)。固定 MajdataPlay 按 prefab 子节点数量分配总时长，与 Visual 的几何长度规则不同；Web 本轮采用 Visual 模型，不把本地往返通过写成 MajdataPlay 的段边界兼容通过。现代逐段括号仍只读保留原文，也不提供未经证实的逐段速度设置。

## 编辑方式

新建普通 Slide 选好时间和终点后，可在路径面板开启“连续路线”。每次手绘或候选点击只向草稿追加一段；后续手绘必须从上一段终点出发。也可选下一段终点再点候选。右键先清除临时候选预览，再移除末段；“撤回末段”直接移除末段；Enter 或“保存整条路线”只提交一次，Esc 放弃全部草稿。

属性中的“编辑连续路线”打开当前分支完整草稿。共享头保持固定，等待和总移动时长不随添加段数改变；整组旋转会依次变换各段起终点和圆弧方向。删除第一支并提升后续分支时保留后者全部连续段。单段快捷放置与 Wi-Fi 对向放置保持原有操作。

解析 DTO 升为 schema 4，检查点写 schema 5。schema 3/4 只接受不含新连续段字段的数据；schema 3 仍禁止新增共享头字段。旧格式不能靠忽略嵌套字段悄悄改变路线，失败时仍可下载原稿。

## 验证入口

`tests/slide-connected-browser.mjs` 走生产页面，检查实际 Worker/WASM 导入、草稿取消、追加和右键撤回、单次撤销/重做、恢复、分支提升、手绘连续性、候选导出及重开；截图覆盖头部、首段运动和后段运动。Core 测试独立核对几何比例、端点连续、变换、深拷贝、无效输入回滚和检查点版本；skin 测试核对续段旋转、条带消退、单星与共享头；音频测试核对连接点无重复提示音。

最终生产构建通过 95 项单元测试（22 个文件）、类型与资源检查、WASM 构建和前端打包。已有 Chromium 153.0.8010.12、1920×1080、DPR 1 下，连续路线 6 组、共享头 5 组、单段编辑 10 组、手绘 5 组流程全部通过，无页面异常。普通编辑、P3 和故障保护的 16 组既有浏览器流程也通过。生产主脚本为 `index-Cc8wAqPq.js`，Worker 为 `chart.worker-aspj87W7.js`，WASM 目录 5,924,046 bytes；哈希见结果文件。

真实 WASM harness 同时通过旧式主链、两个共享分支圆弧例及其含空格写法、现代多括号/Wi-Fi串联/非法直线拒绝、64/65段边界，以及既有基线、Touch/P3、UTF-16 和 1k/10k负载。对旧 harness 中 `A1f` 的过期只读断言，按已实现的 Touch Firework 字段更新为可编辑及字段断言，没有放宽其他只读保护。
