# 支持矩阵与已知限制

2026-09-27 实现范围。解析来自固定 MajSimai 的 C# WASM 宿主，编辑内核与候选导出使用同一语义模型；不另写 TypeScript Simai 解析器。核心与检查器测试为 179 项。测试证据见 [运行时](runtime-validation.md)、[内核](core-validation.md)、[UI](ui-validation.md) 与 [开发记录](implementation-log.md)。

| 内容 | 严格解析 | 编辑 | 预览 | 导出 |
| --- | --- | --- | --- | --- |
| Tap、重复 Tap | 支持 | 放置、移动、删除、复制、批量修改、撤销 | 支持 | 候选重解析核对 |
| 单个 `$` 静态星形 Tap | 支持，保留独立 `forceStar` 字段 | 工具模板、三种放置入口、单音符属性、中键套用、撤销 | 原始静态星形素材，支持 each / Break / EX | 输出单个 `$`，候选语义检查 |
| 双 `$$` 星形旋转、Hold / Touch 上的 `$` | 诊断并只读保留 | 禁用 | 不折叠为静态星形 | 原文保留 |
| 短 Hold `1h` | 支持零时长 | 支持 | 支持 | 保留短 Hold 表达 |

固定版本的代表几何可以离线提取，但仍标记 `source-and-prefab-extraction-only`、`playerBehaviorConfirmed: false`。尚未取得固定播放器的可执行对照证据。单段 `-<>vszw` 在本地闭环验收后开放编辑，仍保留原生待验警告；不能将本地成功解释为目标兼容性通过。操作和限制见 [Slide 编辑验收](slide-edit-validation.md) 、[共享头验收](slide-shared-validation.md) 与 [连续路线验收](slide-connected-validation.md)。

Tap / Hold / Touch 可在圆形 41 区域按住跨区放置与右键删除，外圈和 Touch 工具分别记忆；Touch Hold 终点仍在独立时间轨确定。操作差异与验证见 [圆形输入](place-area-validation.md)。

编号轨道支持左右方向键长按快速放置，按显示顺序循环并逐格推进；Hold 为短 Hold，浏览器显示逻辑光标。行为差异见 [方向键验收](fast-placement-validation.md)。

单段路径面板支持从外圈拖画并重新确定起终点。手绘比较全部 69 条源路径，保留候选顺序和平局取后规则；当前可提交 `-<>vsz`，匹配到其他路径时提示并保留待定状态，不降级为已支持路径。Wi-Fi 使用专用开关。来源与流程见 [手绘验收](slide-paint-validation.md)。

支持多难度切换、BPM、全局偏移、白名单单行元数据、左右 / 上下镜像及 45° 旋转。Touch 的 A/B 与 D/E 使用各自位置映射，中心 C 不旋转。设备校准只影响本机播放，不写回谱面。元数据重复或多行时保持只读；未知字段保留。

原稿下载与候选导出是不同操作。未改文件导出原字节；编辑后只重建受支持且已改动的难度。候选校验失败不会标记为已导出。有只读难度时禁用全局 `&first` 修改。IndexedDB 保存最近一份 schema 5 文档检查点，不存媒体和撤销历史。兼容不含连续段字段的 schema 3/4；schema 3 还需不含共享头字段；无法恢复的旧数据仍可下载原稿。

## 验收范围

- 按用户指示，只使用已有 Chromium 环境完成当前验收，不下载或安装额外浏览器。Chrome / Edge / Safari 没有完整编辑器验收证据，Firefox 适配暂缓。早期独立音频页的 Firefox / WebKit 记录不代表产品通过，也不等同于 Safari 实测。
- 自制合成谱面和人工预期覆盖可编辑家族。用户 `examples/` 是本地参考素材，含未支持语法的难度按只读边界处理；没有把该素材加入发布归档。
- 正常性能负载为 300 秒 / 1,000 个音符；基础 Tap / Hold 与含 100 段 Slide（其中 33 段 Wi-Fi）的只读混合负载分别测量。10,000 音符只作压力观察，取消 50,000 音符测试；新增共享头/连续路线负载已测得均匀/密集可见条带峰值 20/151，帧、热导入和路线编辑输入达到本机预算，见 [性能验收](slide-performance-validation.md)。有曲定位 P95 为34.1/33.5ms。长音频首载加十次换歌 RSS 增量两轮为625.6/494.0 MiB；后轮稳态上升10.8 MiB，尚未稳定通过内存验收，见 [内存记录](audio-validation.md)。
- 软件时钟和浏览器定位测试不等同于扬声器与显示器的物理输出同步测量。尚未进行目标播放器行为验收。

多难度混合语义流程已覆盖共享头镜像、连续路线旋转、BPM 修改、撤销重做、刷新恢复、导出重开及未修改难度原文保留，见 [混合验收](mixed-edit-validation.md)。

新增v/s/z支持范围及64个合法/128个非法端点矩阵、生产UI保存恢复证据见 [v/s/z验收](slide-vsz-validation.md)。v不可同轨或对向，s/z仅对向；大写V仍只读。

时间轴右键菜单支持音符复制/剪切、两阶段粘贴和整组属性；Ctrl/Cmd+V 同样先预览，左键确认、右键取消。Break/EX 批量菜单仅处理 Tap/Hold/Slide，路径 Break 覆盖全部共享分支。BPM 文字可单选、Shift 混选或随音符框选，剪切与粘贴各是一次撤销事务；第 0 拍 BPM 保留，同拍粘贴以新值覆盖，菜单全选只选择音符。拍号暂不参与编辑或剪贴，需独立工程文件保存。详见 [事件剪贴](event-clipboard-validation.md)。两项告警导航按实际秒数跳转并回绕；独立 ChartWatcher 检查涵盖已建模难度的 codes 0–8，按原默认阈值/Visual 拍时长运行，无法保证检查的难度明确显示原因，见 [菜单验收](edit-menu-validation.md) 和 [检查器验收](visual-checks-validation.md)。

时间轨另用原包两张告警 PNG 显示检查结果（全包共 67 张 PNG），悬浮查看同拍全部原因，见 [告警轨验收](warning-track-validation.md)。工作区静态差异与本轮验收见 [差异清单](workspace-differences.md) 和 [续做验收](roadmap-followup-validation.md)；Windows 环境检测按本轮要求暂缓。
