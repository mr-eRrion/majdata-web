# 共享头 Slide 本地验收

2026-09-27。支持每支均为 `-<>w` 单段的 `*` 共享头组合。源码依据见 [共享头语义](slide-shared-source.md)，串联路径的差异见 [连接语义](slide-connected-source.md)。本页确认本地解析、编辑和保存闭环，不宣称已经完成 Visual Maimai 或 MajdataPlay 原生运行对照。

## 数据与操作

一个共享头是一条 Note，起点、拍点、头类型和头部 Break/EX 只保存一次；首路径沿用原 `slide` 字段，第二条起保存到 `additionalPaths`。每支独立保存命令、终点、路径 Break、wait 和 move。显示数据逐支编译，整组结束时间取最长支；头部 Each 与路径 Each 分开推导。每组最多 64 支，全图预算按展开后的路径事件数量计算。

同拍同轨再次放置 Slide，会给已有头追加路径，并保留已有头属性。若该位置原本有多个由 `/` 分开的独立 Slide 头，界面提示消除歧义，不擅自合并。属性面板可切换路径，独立修改命令、终点、路径 Break、等待和移动时长，也可删除当前路径；删除首路径时保留共享头属性，并提升下一条路径。起点旋转、移动、复制、删除整个音符和撤销均以整组为单位。

共享星头有多支时使用原始双星纹理，动态旋转速度采用 Visual 的最短有效移动拍长；静态图标不旋转。Pixi 条带和运动星按每支实际时刻显示，音符头及头音只生成一次；每支移动音和路径 Break 尾音分别生成。时间轴逐支画等待/移动辅助线，仍只有一个可选择的头。合成音色沿用已有实现。

解析 DTO 升至 schema 3，新检查点写 schema 4。不含新增路径字段的 schema 3 检查点仍可恢复；不能完整对照原稿的旧只读数据不伪迁移，保留原稿下载。新版本拒绝在 schema 3 中夹带新增路径字段，旧版本也会拒绝 schema 4，从而避免忽略分支后覆盖恢复数据。

## 实测

全量 84 项单元测试、TypeScript 检查、原素材校验及 Release 构建通过；WASM 目录为 5,909,611 字节。

- `tests/slide-shared-roundtrip-browser.mjs`：真实 Release WASM 的 12 组 star/tap/none 头与 Break/EX 组合，以及 5 组空分支、额外头修饰符、串联和未知路径拒绝样例，共 17 例通过。三支使用不同等待和移动时长，逐项核对人工预期；修复了扫描器把 `*<...` 当成状态命令的问题。
- `tests/slide-shared-browser.mjs`：5 组生产浏览器流程通过。覆盖一头三支导入、独立时长、路径 Each、原字节导出、逐支属性、删首支、整组旋转、撤销重做、追加路径、schema 4 恢复、复制粘贴及候选导出重开；未支持组合仍只读且原字节保留。
- 已有单段编辑 10 组、手绘 5 组、30 例单段时长/修饰符 WASM 往返和 Slide 综合样例回归通过；普通编辑、P3 与故障浏览器流程也通过。综合样例的共享头难度现可编辑，串联与 `?` 难度继续只读。
- 时间轴头部含像素断言，确认双星图片已加载并绘制；预览截图检查三支同时运动以及较短路径结束后最长支继续运动的状态。界面测试使用已有 Chromium 153.0.8010.12、1920×1080、DPR 1；未安装额外浏览器。

结果归档见 [生产流程](results/2026-09-27/slide-shared.json) 与 [WASM 样例](results/2026-09-27/slide-shared-roundtrip.json)。连接 Slide 的逐腿时长与几何仍未开放；原生像素、播放器行为、实体音频同步及共享头高密度性能仍待验证。
