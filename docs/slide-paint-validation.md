# Slide 手绘候选匹配

本项补齐单段路径面板的鼠标拖画输入，沿用现有 `-<>w` 可编辑范围。原程序手势、面板参考尺寸及匹配算法的静态证据见 [源码与场景依据](slide-paint-source.md)。浏览器验收结果在本文末尾记录；原生运行对照仍未取得。

## 数据与匹配

`prepare-slide-match-paths.mjs` 从已有 `rendering.json` 生成独立的 `slide-match-paths.json`，包含 69 条唯一原始路径、73 条有序路径引用和 64 组起终点组合，共 552 个候选引用。生成器进入 `prepare:skin` 和 `check:skin`；保留 fixture、程序集哈希及源对象编号。现有预览用的 21 条基础路径数据不变。

匹配沿用源顺序，比较所有可用于该起终点的路径，包括尚未开放编辑的路径。手绘点先旋转到以 1 号轨为起点的坐标系，再按累计弧长归一化采样。沿源路径从起点到终点遍历原顶点，累计对应手绘采样点的欧氏距离，以顶点数取平均；同分取后一个候选。起点 3–6 对 `<` 与 `>` 的命令互换独立处理。

数值计算使用 JavaScript 双精度；fixture 的路径长度由提取器按点列求和，不是序列化的单精度长度字段。候选次序、采样与比较规则按源码恢复，但不能据此保证接近评分分界的笔迹与 Unity 单精度计算逐位相同；该边界仍需要目标运行对照。

若最优结果属于未开放的路径，界面显示识别结果并保留待定放置，不提交、也不从已支持候选中另找一个替代。用户可重新绘制，或主动选择原起终点的按钮候选。Wi-Fi 继续使用专用开关，不属于源 `GetSelections` 手绘候选。

## 输入与事务

按下位置需满足绘画逻辑坐标中半径大于 `10 / 3`、小于 `5`；超过原参考面板中的 20 单位位移后才开始绘制。参考面板为 590×590，因此归一化阈值为 `20 / 590 × 10`。起点采用触发当帧最近的轨道，采样相邻点间距至少 0.03；松开时追加最近终点的源轨道坐标。轨道距离相同取后者，终点不额外设置半径限制。

Web 使用当前预览的比例和中心，将指针反算为 Unity Y-up 逻辑坐标；面板视觉保留 Web 工作区的缩放，因此不是原面板的像素复刻。辅助白线用于显示手绘输入，不替代音符或路径纹理。鼠标捕获保持移出边界后的拖画连续性；取消、失焦或浏览器 pointer cancel 只清理未提交手势。

短路径绘画可重新确定起终点，但不改变此前确定的命中、移动起点与结束时间。匹配到可编辑路径后直接提交一个完整音符事务；一次撤销移除整笔新增。同拍同轨追加路径仍未实现，碰撞会显示错误，保留面板让用户取消或重画。Esc 取消整笔放置，正在绘制时右键不打断；未绘制时右键清除候选预览。

## 验收

77 项单元测试、类型检查、素材/全路径投影一致性检查及生产构建通过。新增 3 项单测检查起点旋转与圆弧命令互换、中间轨道回绕、未支持类型不降级和平局取后。当前生产入口为 `index-B9XpcwhU.js`；没有修改 WASM 宿主或谱面模型。

已有 Chromium 153.0.8010.12、1920×1080、DPR 1，`tests/slide-paint-browser.mjs` 的 5 组生产流程通过：手绘 `2-6`、`3<7`、`8>2` 改变初始端点并自动提交，一次撤销/重做和真实 Worker 导出重开保持模型及绝对时刻；完整候选中的 `1v4` 被明确拒绝，重画合法直线可继续提交；中心起笔忽略、绘制中 Esc 取消不产生历史。页面异常为 0。原有 `slide-edit-browser.mjs` 的 10 组编辑/模板/取消/恢复回归通过。

报告见 [手绘浏览器结果](results/2026-09-27/slide-paint.json)，截图见 [未支持候选提示](results/2026-09-27/slide-paint-unsupported.png)。目标程序的原生像素、输入手感以及未支持路径的编辑闭环仍单独待验。
