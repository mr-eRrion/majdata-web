# 时间轴编辑菜单验收

## 实现范围

来源与限制见 [源码核对](edit-menu-source.md)。有效空白轨道右键抬起打开 Edit 菜单；已有 Hold / Slide / 粘贴草稿的撤回和音符右键删除优先处理。菜单沿用源顺序，提供撤销、重做、选择、音符剪贴、删除、镜像旋转及批量属性。Break / EX 只作用于 Tap、Hold、Slide；路径 Break 修改选中 Slide 的全部共享分支，保留头部属性和时长。

菜单与 Ctrl/Cmd+V 使用两阶段音符粘贴：悬停吸附拍处显示预览，左键抬起提交一次事务，右键取消；保持轨道、Touch 区域及相对拍差。侧栏明确标为“粘贴至播放头”的便捷入口继续直接粘贴。BPM / 拍号 keyframe 选区与剪贴尚未接入；两项 Warning 导航后续已接入独立碰撞结果，见 [检查器验收](visual-checks-validation.md)，不以解析诊断替代。

菜单位置按实际尺寸限制在视口内；键盘支持方向键、Home/End、Escape 和 Tab，点击外部或失焦关闭。Escape 和动作结束恢复之前的焦点，外部点击不抢回焦点。这些键盘与无障碍行为为 Web 适配，源类未发现 Escape 绑定。菜单外观还没有原生同视口对照。

## 验证

2026-09-27，现有 Chromium 153.0.8010.12、1920×1080、DPR 1，生产入口 `index-DzjdcFNV.js`（SHA-256 `6d4bc3465bef33180964da67cd947a35e3c14176000b1fa0474bda0327483860`），Worker `chart.worker-DnxaBYKk.js`。`tests/edit-menu-browser.mjs` 的 16 组流程通过，页面错误 0，见 [原始结果](results/2026-09-27/edit-menu.json)。

- 20 项顺序与禁用状态；空白轨道仅右键抬起打开；实际尺寸限制在视口内。
- 空谱全部动作禁用时菜单本身获得焦点，Space 不穿透；方向键循环跳过禁用项、Escape 恢复焦点，外部点击关闭，Delete 不触发全局删除。
- 全选、复制、鼠标及 Ctrl+V 粘贴先预览；左键抬起才提交，以落点而非播放头/菜单位置为锚。跨 BPM 的整组相对拍差、lane、Touch 区域、连续与共享 Slide 数据保持。
- 右键取消粘贴不删除音符也不打开菜单；整组一次撤销/重做，剪切再粘贴保留共享路线；批量属性经真实候选导出与 WASM 重开保持。
- Break/EX 排除 Touch/TouchHold；路径 Break 修改所有共享分支，不改变头部样式。
- Hold / Slide 草稿的右键取消和音符右键删除优先；将编辑请求延迟 200ms 后连续两次右键删除仍全部提交，没有因第一笔版本变化丢失第二笔。
- 切换文档取消待粘贴数据并关闭旧菜单；只读难度允许选择复制，禁用突变，原稿导出字节不变。

[菜单截图](results/2026-09-27/edit-menu-open.png) 和 [粘贴预览截图](results/2026-09-27/edit-menu-paste-ghost.png) 已目检，未见越界或文本裁切。菜单布局与目标原生的像素对照仍未完成。

类型检查、104 项单测、65 PNG / 29 运行路径 / 69 手绘匹配路径校验及前端生产构建通过。基础编辑、播放头直接粘贴、导出重开、只读保护和 IndexedDB 恢复回归通过；[中键播放头](results/2026-09-27/edit-menu-scrub-regression.json) 与 [10 组中键模板回归](results/2026-09-27/edit-menu-template-regression.json) 通过。WASM 与 Core 模型未改动，本轮没有重复生成解析宿主。

## 审查修复

空菜单焦点回退到菜单容器，避免全局热键穿透。进入菜单只停止快速放置，不误触发菜单关闭。右键普通删除继续按文档代次/难度串行处理；严格版本校验只用于迟到菜单和待粘贴预览，避免漏掉队列中的下一笔删除。
